BCBC Agent Control

Safe static control panel for local AI agents, Ollama models, and copy-ready operator commands.

Static page No browser shell Operator-run commands LAN demo ready

Safety Boundary

This page does not execute arbitrary shell commands from the browser. Commands are copied and run intentionally by the operator.

Dexter Agent Status

Run on Dexter to check the local AI agent service.

systemctl status dexter.service --no-pager

Dexter Recent Logs

Show the latest service output without opening a full pager.

journalctl -u dexter.service -n 80 --no-pager

Ollama Status

Check whether the local Ollama model service is running.

systemctl status ollama.service --no-pager

List Ollama Models

Show installed local models.

ollama list

Running Models

Show active loaded Ollama models and CPU/GPU split.

ollama ps

GPU Status

Useful on Dexter/Baxter when NVIDIA drivers and Ollama acceleration matter.

nvidia-smi

Local AI Demo Command

Use this for a quick, visible demo that shows a local model responding from terminal.

ollama run qwen2.5-coder:7b 'In one sentence, explain why local AI can be useful for a technician.'

Baxter Hub Mount Check

Run from a client machine to confirm the central Baxter share is mounted as a local folder.

mount | grep bcbc-hub || true
ls -lah /mnt/bcbc-hub
