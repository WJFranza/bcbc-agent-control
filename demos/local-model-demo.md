# Local Model Demo

## Goal

Show that a local Ollama model can respond without using a browser-hosted AI service.

## Command

```bash
ollama run qwen2.5-coder:7b 'In one sentence, explain why local AI can be useful for a technician.'
```

## What to explain

- The model is running locally.
- The operator can test it directly from terminal.
- The browser page is only a safe command guide.
